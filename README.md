# 🌐 MVC2024 Web Application

ยินดีต้อนรับสู่ **MVC2024** แอปพลิเคชันตัวอย่างที่สร้างขึ้นเพื่อสาธิตแนวคิดและวิธีการทำงานของ Model-View-Controller (MVC) ด้วยเทคโนโลยีเว็บสมัยใหม่

## 📌 คุณสมบัติที่สำคัญ

- **สถาปัตยกรรม MVC**: แสดงตัวอย่างการจัดการข้อมูลผ่าน Model, View และ Controller อย่างเป็นระบบ
- **การจัดการข้อมูล**: สาธิตการใช้งาน CRUD (Create, Read, Update, Delete) อย่างครบถ้วน
- **อินเทอร์เฟซผู้ใช้งานที่เป็นมิตร**: ใช้งานง่าย เข้าใจง่าย และเหมาะสมกับการเรียนรู้

## 🚀 วิธีการติดตั้ง

1. โคลนโปรเจกต์ไปยังเครื่องของคุณ:

   ```bash
   git clone https://github.com/Celimine09/MVC2024.git
   ```

2. ติดตั้ง dependencies:

   ```bash
   npm install
   ```

3. เรียกใช้งานโปรเจกต์:

   ```bash
   npm start
   ```

4. เปิดเบราว์เซอร์แล้วไปที่:

   ```bash
   http://localhost:3000
   ```
